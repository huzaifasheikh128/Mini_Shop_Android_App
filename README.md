
# Mini Shop Android Application

## Description
Mini Shop is a basic shopping application developed
using Android Studio, Java, and XML.

## Features
- Splash Screen
- Login and Registration
- Forgot and Reset Password
- Landing Screen with GridLayout
- Products Screen
- Add to Cart functionality
- Shopping Cart with total price
- Profile Screen and Logout
- Light and Dark Mode support

## Technologies
- Java
- XML
- Android Studio
- Android Resources
- Explicit Intents

## Navigation Flow
Splash → Login → Landing Screen

Landing Screen → Products → Shopping Cart

Landing Screen → Profile → Logout

Login → Register

Login → Forgot Password → Reset Password
